# Week 2: Advanced SQL – Constraints, Keys & Relationships

Welcome to **Week 2** of my MySQL Learning Journey.

This week focuses on building reliable and well-structured databases by learning SQL constraints, keys, table relationships, and joins. These concepts are essential for designing relational databases and writing advanced SQL queries.

---

## 🎯 Week Objectives

By the end of this week, I will be able to:

- Understand the importance of SQL constraints.
- Apply constraints to maintain data integrity.
- Differentiate between Primary Keys and Foreign Keys.
- Understand relationships between database tables.
- Retrieve data from multiple tables using SQL JOINs.
- Build relational database structures using best practices.
