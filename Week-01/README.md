# Week 1 - MySQL Fundamentals

Welcome to Week 1 of my MySQL Learning Journey.

This week focuses on understanding the fundamentals of relational databases and learning the core SQL commands needed to create, manage, and retrieve data.

---

## 🎯 Week Objectives

By the end of this week, I aim to:

- Understand database fundamentals.
- Learn the MySQL ecosystem.
- Create databases and tables.
- Insert, retrieve, update, and delete data.
- Perform basic data analysis using SQL aggregate functions.
