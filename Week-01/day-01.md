## 📖 Introduction

Before learning SQL commands, it is important to understand the concepts behind databases.

Every application we use—such as Instagram, Amazon, Netflix, or a banking system—stores and manages large amounts of information. Databases provide an organized way to store this information, while SQL allows us to retrieve and manipulate it efficiently.

This lesson introduces the fundamental concepts required before working with MySQL.
## 📌 What is Data?

Data is a collection of raw facts, figures, or observations that can be stored and processed to produce meaningful information.

Data can be in many forms, such as:
- Numbers
- Text
- Images
- Videos
- Dates

### 🌍 Real-world Example

Consider a student admission form.

- Name: Mitali
- Age: 21
- Course: Full-Stack Java
- City: Pune

Each of these values is an example of data.

### 💡 Why is Data Important?

Data helps organizations make decisions, maintain records, analyse trends, and provide services efficiently.
## 📌 What is a Database?

A database is an organized collection of related data that is stored electronically and can be easily accessed, managed, and updated.

Instead of storing information in multiple notebooks or spreadsheets, a database keeps everything in one organized place.

### 🌍 Real-world Example

Imagine a library.

- Books represent the data.
- The library represents the database.

The library stores thousands of books in an organized way, making it easy to find any book when needed.

Similarly, a database stores information so that applications can retrieve it quickly and efficiently.

### 💡 Why Do We Need Databases?

Databases help us:

- Store large amounts of information.
- Retrieve data quickly.
- Update records easily.
- Reduce data duplication.
- Improve data security.

## 📌 What is DBMS?

A **Database Management System (DBMS)** is software that allows users to create, store, retrieve, update, and manage data in a database.

Instead of interacting with the database directly, users communicate with the DBMS, which handles all database operations.

### 🌍 Real-world Example

Imagine a library again.

- The **books** represent the data.
- The **library** represents the database.
- The **librarian** represents the DBMS.

When you need a book, you ask the librarian instead of searching the entire library yourself. Similarly, a DBMS manages the database and performs operations on your behalf.

### 💡 Responsibilities of a DBMS

A DBMS helps to:

- Store data securely.
- Retrieve information quickly.
- Insert new records.
- Update existing records.
- Delete unwanted records.
- Control access to the database.

## 📌 What is RDBMS?

A **Relational Database Management System (RDBMS)** is a type of DBMS that stores data in the form of related tables.

Each table consists of rows and columns, and relationships can be established between tables using keys.

### 🌍 Real-world Example

Consider a school database.

There may be separate tables for:

- Students
- Teachers
- Courses

These tables are connected using common fields, allowing related information to be retrieved efficiently.

### 💡 Why Use an RDBMS?

An RDBMS provides:

- Better data organization.
- Reduced data duplication.
- Improved data consistency.
- Support for relationships between tables.
- Powerful querying using SQL.

## 📌 What is SQL?

**SQL (Structured Query Language)** is the standard language used to communicate with relational databases.

Using SQL, we can create databases and tables, insert data, retrieve information, update records, and delete unwanted data.

SQL acts as the bridge between users and the database.

### 🌍 Real-world Example

Imagine a librarian who understands only one language for requests.

Instead of saying, "Can you find my book?" in any random way, you use a standard language that the librarian understands.

Similarly, SQL is the standard language that databases understand.

### 💡 What Can We Do Using SQL?

With SQL, we can:

- Create databases and tables.
- Insert new data.
- Retrieve specific information.
- Update existing records.
- Delete unwanted records.
- Analyse data using built-in functions.

## 📌 What is MySQL?

**MySQL** is an open-source Relational Database Management System (RDBMS) that uses SQL to store, manage, and retrieve data.

It is one of the most widely used database systems for web applications, enterprise software, and learning SQL.

### 🌍 Real-world Example

Consider an online shopping application.

MySQL stores information such as:

- Customer details
- Product information
- Orders
- Payments

Whenever a customer places an order, the application stores and retrieves data from MySQL.

### 💡 Why Learn MySQL?

MySQL is popular because it is:

- Easy to learn.
- Open source.
- Fast and reliable.
- Widely used in the software industry.
- Compatible with many programming languages, including Java, Python, and PHP.

## 📝 Key Takeaways

- Data represents raw facts and figures.
- A database stores related data in an organized manner.
- A DBMS helps users manage databases efficiently.
- An RDBMS stores data in related tables.
- SQL is the standard language used to interact with relational databases.
- MySQL is a popular open-source RDBMS that uses SQL.
